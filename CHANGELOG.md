# Changelog

What changed in each release. The Docker image is
`ghcr.io/tim80732/itinerary-builder`; release pages are on the
[Releases page](https://github.com/tim80732/itinerary-builder/releases).

## 1.0.0 — 2026-11-01

First release: builds a travel itinerary card by card and exports it as one
self-contained HTML file (calendar, printable schedule, cost summary and
every booking document embedded, for offline use). Also serves a read-only
live link per trip and a JSON API for agents; changes made through the API
show in the project history as "API: …". Docker image on ghcr.io with an
Unraid template.
